# Agent Instructions

This repo is maintained by humans and AI agents. Agents should read this file first.

## Required maintenance rule

Whenever you change or add any dotfile, you must recheck and update both:

- `bin/bootstrap`
- `README.md`

This keeps the setup reproducible on a fresh machine.

## Working directory

- Dotfiles live under this repo root.
- Config files go in `.config/`.
- Executable scripts go in `bin/` and should be marked executable.
